# Smart Cradle Automation System

An automated child healthcare IoT solution designed to actively monitor ambient cradle environment variables to keep infants dry, safe, and comfortable. This project secured **1st Rank** across the annual college-level technical project exhibition during my 1st semester.

## Core Features
* **Environmental Monitoring:** Utilizes an ESP32 microcontroller linked with localized sensory inputs to evaluate cradle dampness thresholds.
* **Proactive Health Safeguards:** Programmed real-time sensing response routines inside the Arduino IDE environment to immediately flag active moisture anomalies.
* **Automated Risk Mitigation:** Deployed sensory feedback loops to handle minor comfort parameters and successfully minimize infant diaper rash risks and skin infections.

## Tech Stack
* **Microcontroller:** ESP32 Module
* **Firmware Framework:** Arduino IDE Architecture
* **Core Language:** C++
* **Sensory Interfacing:** Moisture Sensors, Analog-to-Digital Processing (ADC)
